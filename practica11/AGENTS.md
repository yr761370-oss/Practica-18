AGENTS.md

Objetivo

Crear un sitio web One Page muy sencillo, limpio y responsive usando únicamente HTML y CSS.

Tecnologías permitidas

HTML5

CSS3

No utilizar frameworks, librerías, generadores ni JavaScript.
No usar Bootstrap, Tailwind, React, Vue, Angular, jQuery ni dependencias externas.

Estructura del sitio

El sitio debe ser una sola página (index.html) con exactamente estas tres secciones principales:

INICIO

Presentación breve del sitio.

Un título principal.

Una llamada a la acción que lleve a Productos o Contacto.

PRODUCTOS

Mostrar los productos de forma clara y sencilla.

Utilizar tarjetas o una cuadrícula CSS.

Cada producto puede incluir nombre, descripción breve y precio.

CONTACTO

Mostrar información básica de contacto.

Incluir un formulario sencillo con nombre, correo y mensaje.

El formulario no necesita funcionalidad de backend.

Navegación

Incluir un menú superior con enlaces internos a #inicio, #productos y #contacto.

Los enlaces deben desplazarse a las secciones correspondientes.

Utilizar HTML semántico (header, nav, main, section, footer).

Diseño

Diseño minimalista y fácil de leer.

Responsive para móvil, tablet y escritorio.

Usar CSS Grid o Flexbox cuando sea útil.

Mantener una jerarquía visual clara.

Evitar animaciones innecesarias.

No depender de imágenes externas para que el sitio funcione.

Archivos

Como mínimo:

/
├── index.html
└── styles.css

Reglas de implementación

Mantener HTML y CSS separados.

Usar etiquetas semánticas y atributos alt cuando existan imágenes.

Mantener el código limpio, legible y sencillo.

No añadir funcionalidades que no hayan sido solicitadas.

No instalar dependencias.

No utilizar JavaScript.

Comprobar que todos los enlaces internos funcionen.

Comprobar que el diseño sea usable en pantallas pequeñas.

Criterios de aceptación

El resultado se considera correcto si:

Es una única página.

Contiene únicamente las secciones INICIO, PRODUCTOS y CONTACTO.

La navegación permite saltar entre las tres secciones.

Está construido exclusivamente con HTML y CSS.

No utiliza frameworks ni JavaScript.

Es responsive.

El código es claro y fácil de modificar.
